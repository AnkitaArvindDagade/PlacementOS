# PlacementOS

A private placement preparation workspace for managing company-wise topic progress and study sessions.

🔗 **Live Project**: https://placementos-git-main-ankitaarvinddagades-projects.vercel.app/

## Overview

PlacementOS is built with Next.js 15, React 19, and MongoDB. It's a single-owner private workspace with secure authentication.

## Local Development

```bash
npm install
npm run dev
```

See `.env.example` for required environment variables.

## Deployment

Deploy on Vercel with the required environment configuration.
